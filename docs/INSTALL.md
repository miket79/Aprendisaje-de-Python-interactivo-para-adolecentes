# Install Python Quest · Instalar Python Quest

**App link · Enlace de la app:** <https://miket79.github.io/Aprendisaje-de-Python-interactivo-para-adolecentes/>

## English

Python Quest installs from your browser like an app. You don't download any file, and your computer won't show security warnings. After the first visit it works **without internet**.

| Device | How to install |
|---|---|
| **Chromebook, Windows or Mac with Chrome or Edge** | Open the link and click **Install app** (top right). You can also use the install icon in the address bar. |
| **Mac with Safari** (macOS 14+) | Open the link and choose **File → Add to Dock**. |
| **iPhone / iPad** | Open the link in Safari and tap **Share → Add to Home Screen**. |
| **Android** | Open the link in Chrome and tap **⋮ → Install app**. |

- The first time, it downloads about 16 MB, including Python itself. Wait for **"Python Quest is ready to work offline"** before you go offline.
- When there's a new version, you'll see **"A new version is ready" → Update**.
- Your progress is saved on that device. Uninstalling the app or clearing the browser's data erases it.
- On a school-managed device that won't let you install apps, just use the link. It still works offline after the first visit.

## Español

Python Quest se instala desde el navegador como una app. No descargas ningún archivo y tu computadora no muestra advertencias de seguridad. Después de la primera visita funciona **sin internet**.

| Dispositivo | Cómo instalar |
|---|---|
| **Chromebook, Windows o Mac con Chrome o Edge** | Abre el enlace y haz clic en **Instalar app** (arriba a la derecha). También puedes usar el ícono de instalar en la barra de direcciones. |
| **Mac con Safari** (macOS 14 o superior) | Abre el enlace y elige **Archivo → Añadir al Dock**. |
| **iPhone / iPad** | Abre el enlace en Safari y toca **Compartir → Agregar a inicio**. |
| **Android** | Abre el enlace en Chrome y toca **⋮ → Instalar app**. |

- La primera vez descarga unos 16 MB, incluido Python. Espera el mensaje **"Python Quest ya funciona sin internet"** antes de desconectarte.
- Cuando haya una versión nueva verás **"Hay una nueva versión" → Actualizar**.
- Tu progreso se guarda en ese dispositivo. Si desinstalas la app o borras los datos del navegador, se pierde.
- Si usas un equipo de la escuela que no permite instalar apps, usa el enlace directamente. También funciona sin internet después de la primera visita.
